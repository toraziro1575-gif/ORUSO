# ORUSO Ver.0.7

Ver.0.5までのホーム・筋トレ・食事・カレンダー・体重機能と、
Ver.0.6のORUSO IDログイン・クラウド保存・フレンド・プロフィールを統合した版です。

## 画面
- ホーム
- 筋トレ
- 食事
- カレンダー
- 体重
- フレンド
- マイページ

## 主な機能
- ランダムORUSO ID＋パスワード
- Firebaseクラウド保存
- 筋トレの重量・回数・セット・時間・メモ
- 自己ベスト通知
- 食事種類・内容・メモ
- 曜日つきカレンダー
- 日付ごとの筋トレ・食事・体重まとめ表示
- フレンド検索・申請・承認
- ニックネーム・自己紹介・公開範囲
- ORUSO公式アイコン
